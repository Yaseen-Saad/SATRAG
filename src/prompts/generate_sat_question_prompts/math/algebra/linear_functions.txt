- "Linear functions": Evaluate f(x) for given inputs, interpret function notation, and understand domain/range. Easy: f(x) = 2x + 3, find f(5). Medium: given f(x) = ax + b, find x when f(x) = k. Hard: piecewise linear contexts, comparing two linear function models (e.g., "Plan A costs $5/month plus $1/GB. Plan B costs $0 flat plus $3/GB. After how many GB do the plans cost the same?").
- Wrong answers should test common mistakes: confusing f(a) with a·f(x), evaluating at wrong input, misinterpreting function notation.
