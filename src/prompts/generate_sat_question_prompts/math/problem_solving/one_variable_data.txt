- "One-variable data: distributions and measures of center and spread": Read histograms, box plots, dot plots. Calculate/interpret mean, median, mode, range, IQR, standard deviation. Easy: find the mean of {2, 4, 6, 8}. Medium: interpret a box plot to find median and IQR. Hard: compare distributions, identify outliers, or determine which measure of center is most appropriate given a skewed distribution.
- When describing data displays, include the actual values in the question text (e.g., "The box plot shows: minimum = 12, Q1 = 18, median = 24, Q3 = 30, maximum = 42").
- Wrong answers should test common mistakes: confusing mean and median, miscalculating IQR, using range instead of IQR for spread.
